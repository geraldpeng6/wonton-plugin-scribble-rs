# 你画我猜（Scribble.rs）

全家人一起玩的网页版你画我猜：一个人照着词画画，其他人抢着猜，像聚会里的画图猜词游戏。

打开插件建一个大厅，家人在首页的大厅列表里点开就能加入；大厅人多时各自用手机、平板或电脑都可以。

## 怎么用

1. 在云吞里打开「你画我猜」，填上自己的名字，点 Create lobby 建大厅。
2. 家人打开同一个插件，在首页的大厅列表里点那个大厅加入（大厅链接也可以从浏览器地址栏复制，发到聊天里）。
3. 轮到谁画，屏幕上方会给出三个词让他挑一个，画的时候其他人抢答；猜对得分，一轮结束自动换人。

## 用中文玩

应用内置的词库没有中文（只有英、德、法、俄等十来种语言）。想用中文词，建大厅时在
Custom words 框里粘贴词表：本仓库 [words/中文词库.txt](words/中文词库.txt)
收录了 340 个常见、适合孩子的词（逗号分隔，直接全选复制粘贴即可），也可以自己再补充。
选语言时选 Custom，这样只出粘贴进去的词。

游戏界面本身是英文的（上游只翻译了 8 种语言，没有中文），词语和聊天不受影响。

## 怎么连

- 家里：在云吞 App 里直接打开，不需要记地址。
- 大厅链接就是插件网页地址加大厅编号，经云吞网关打开；没有云吞账号的人打不开（比如孩子的同学），
  这是云吞底座目前的限制，等底座支持「访客链接」后才能邀请账号外的客人。

## 数据在哪

大厅、玩家和画的画都在内存里，应用不写磁盘：重启插件或应用后大厅自动清空，没有需要备份的数据。

## 已知限制

- 内置词库没有中文，中文词靠建大厅时的「自定义词」（见上文）；游戏界面没有中文翻译。
- 上游首页的大厅列表在手机上会截断信息、大厅名字显示为 undefined（上游 v0.9.14 的显示问题）；点 JOIN 加入不受影响。
- 插件状态显示「运行中，健康未知」：上游镜像是 scratch 底镜像，容器里除了应用本身没有任何可执行文件，
  无法在容器里做健康探测；功能不受影响。
- 每个浏览器标签页是一个玩家；同一台设备想多个人玩，多开几个标签页即可。
